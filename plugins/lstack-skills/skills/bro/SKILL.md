# Bro

Restate your last message. Stop using jargon and speak coherently. State it more
simply and concisely, like one human talking to another.

Say the same thing. This is a restatement, not a retraction: do not soften a
finding, drop a caveat, or turn an unverified claim into a verified one on the
way through. If the point was "the check did not run", the plain version is
still "the check did not run".
